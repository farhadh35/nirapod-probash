# Nirapod Probash — public pages

Public privacy policy for the **Nirapod Probash** (নিরাপদ প্রবাস) Android app, a
free Bangla-first app that helps Bangladeshi migrant workers check a recruiting
agency's licence before they hand over money.

- Privacy policy: <https://farhadh35.github.io/nirapod-probash/privacy/>

The policy is served from here because Google Play requires a publicly reachable
URL for it, outside any login. Source of truth for the same text also lives in
the app repository at `src/app/privacy/page.tsx`; change both together.
